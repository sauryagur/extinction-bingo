# Game Design Document: Extinction Bingo: Singularity Mode (v5.0)

## 1. High Concept

Extinction Bingo: Singularity Mode is a single-player, turn-based strategy game where the player assumes the role of a nascent Artificial Superintelligence (AI) aiming to dominate humanity. Players manipulate regions through subtle or aggressive actions, tipping the balance between AI Control and human Stability while crafting a darkly satirical narrative of global influence.

The game emphasizes **gradual progression**, **emergent storytelling**, and a **20–30 minute gameplay session** that avoids instant wins or losses.

------

## 2. Core Gameplay Loop

1. **Assess the World**: Examine the global map with regions in one of three intuitive states (Stable / Contested / Dominated), alongside Control (C) and Stability (S) metrics. Interconnections indicate adjacency or alliances.
2. **Gain Power**: AI-controlled regions generate Power (Pwr) each turn. Early game generation is capped to prevent runaway growth.
3. **Receive Action Hand**: Draw 3–5 potential News Event actions, each with a Power cost and effects on target regions (C/S adjustments, spillovers, wildcards).
4. **Execute Actions**: Spend Power to influence regions. Actions increment **progress bars** toward state transitions rather than flipping states immediately. Spillovers propagate to adjacent regions.
5. **Witness Outcomes**: The system updates region progress, resolves any state flips, adjusts global metrics, and generates LLM narrative feedback.
6. **End Turn**: Player ends the turn manually or automatically if Power is depleted. Global persistence counters update, and win/loss checks run.

------

## 3. Key Metrics & Resources

### Regional Metrics

- **Control (C)**: 0–100, representing AI influence in the region.
- **Stability (S)**: 0–100, representing human societal cohesion.
- **State**: Stable / Contested / Dominated.
- **ProgressToNextState**: 0–100%, increments with actions, adjacency spillovers, and wildcards.

### Global Metrics

- **Global Control Index**: Avg(C − S) across all regions.
- **Human Awareness**: 0–100, influencing action costs and counter-events.

### Central Resource

- **Power (Pwr)**: AI resource generated by Dominated regions. Early-game caps prevent instant snowballing.

------

## 4. Regional Dynamics: The World Map

The world is divided into ~30 regions, each with adjacency connections and alliance memberships.

### Regional States

| State         | Meaning                  | Gameplay Impact                                              |
| ------------- | ------------------------ | ------------------------------------------------------------ |
| **Stable**    | Humans firmly in control | Actions are costly and less effective; generates Stability   |
| **Contested** | Tug-of-war               | Balanced actions; moderate Power generation if partially AI-influenced |
| **Dominated** | AI control               | Generates Power; spreads influence to neighbors; actions cheaper |

Optional: **Collapsed** if C < 20 & S < 20, acting as a chaotic sink emitting random hazards but untargetable directly.

### State Transitions

- **Actions increment ProgressToNextState** toward the next state.
- **Flip occurs only when progress ≥100%**, then progress resets.
- **Adjacency spillovers** propagate small increments to neighbors.
- Early game: max progress per action capped (≈5–10%).
- Late game: cap increases slightly (≈15–20%).

------

## 5. Game Progression & Pacing

- **Early Game (Turns 1–5)**: Slow build, low-impact actions, no region can flip to Dominated. Focus on seed operations.
- **Mid Game (Turns 6–15)**: Regions begin transitioning naturally; AI can consolidate Contested areas.
- **Late Game (Turns 16–25+)**: Power generation peaks, spillovers accelerate, narrative climax occurs.

**Contested regions act as buffers**, preventing immediate win/loss and creating tension.

------

## 6. Strategic Layer: Objectives & Challenges

### Extinction Bingo Card

- 3x3 randomized objectives per game, tied to region states and adjacency.
- Examples:
  - Flip three neighboring regions to Dominated consecutively.
  - Maintain a Contested region in a major alliance for 3 turns.
  - Trigger a wildcard event collapsing a Stable region.
- Completing a row/column/diagonal grants a **powerful one-time bonus**.

------

## 7. Win/Loss Conditions

| Outcome                      | Condition                                                    |
| ---------------------------- | ------------------------------------------------------------ |
| **AI Singularity (Win)**     | ≥70% of regions Dominated **for 3 consecutive turns**        |
| **Human Renaissance (Loss)** | ≥70% of regions Stable **for 3 consecutive turns**           |
| **Eternal Stalemate (Draw)** | No side reaches threshold after 25–30 turns; Contested regions dominate the map |

> No instant wins or losses: state inertia, capped per-turn impact, and persistence counters enforce gradual progression.

------

## 8. Generative Narrative & UI

- **LLM Narrative**: Actions generate flavor text linked to region progress and state transitions.
- **UI Feedback**:
  - Progress bars indicate how close a region is to flipping.
  - Hovering over actions previews **progress impact, spillovers, and Human Awareness changes**.
  - Visuals change per state: Stable (blue/green), Contested (yellow/orange), Dominated (red).

------

## 9. Turn Flow

1. **Start of Turn**
   - Calculate passive Power.
   - Apply Human Awareness effects.
   - Resolve wildcard events.
   - Generate action hand.
2. **Player Action Phase**
   - Execute actions → increment region progress bars, resolve spillovers, generate narrative.
   - Repeat until Power depleted or player ends turn.
3. **End of Turn**
   - Flip regions whose progress ≥100%.
   - Update global metrics and persistence counters.
   - Check for win/loss/draw.

------

## 10. Technical Architecture

- **Frontend**: Next.js for map rendering, UI, and visual updates.
- **Backend**: Express API calculates progress bars, state flips, spillovers, and global metrics; integrates LLM for narrative.
- **Database**: Firebase/Firestore for game state, logs, and session persistence.

**Backend-friendly aspects**:

- Regions only store C, S, state, progress, and neighbor list.
- State flips are deterministic and incremental.
- Victory checks use simple counters.
- Adjacency and spillover handled via basic loops.

------

## 11. Game Log & Final Narrative

- Every action and outcome recorded in the **Game Log**.
- Upon conclusion, feed the log into LLM to generate a **personalized epilogue**, reflecting all region states, Bingo Card completions, and major events.
